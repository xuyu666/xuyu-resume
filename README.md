## 本地预览

在项目目录运行静态 HTTP 服务后打开 index.html。网页无需安装依赖或编译。

## 更新发布

将 index.html、styles.css、script.js 和 .nojekyll 上传到仓库 main 分支根目录。GitHub Pages 使用 main 分支的根目录自动发布。
